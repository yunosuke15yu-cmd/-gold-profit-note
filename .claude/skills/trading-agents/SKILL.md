# TradingAgents チーム実行手順

XAUUSDについて、6人のエージェントで分析 → 討論 → 計画 → リスク承認 を行います。**分析と提案だけで、発注やMT5の操作は絶対にしません。**

取引口座は **HFMのKATANA口座** です。KATANA口座はアプリに同期していないので、価格データはダッシュボードのHFM価格を使い、残高はユーザーから受け取ります。

引数で指示があればそれに従います(例: `残高=100000`、`スイング`、`討論3ラウンド`)。指定が無ければデイトレ、討論2ラウンドです。**残高の指定が無ければ、始める前にユーザーにKATANA口座の残高(円)を聞きます。**

## 0. 準備
1. 保存先を作る: `reports/trading-agents/<JSTの日付>_<HHMM>/`
2. スナップショットを取る: `python3 tools/trading_agents_data.py --balance <KATANA残高> > <保存先>/00_snapshot.json`
   (価格はM1/M5/M15/H1を取得し、H4とD1はH1から作る。売買記録は同期中の2口座の合算で、参考として使う)
   (読み取り専用のダッシュボードAPIを使う。失敗したらユーザーに伝えて止める)

## 1. 調査(並列)
次の2人を **同じメッセージで並列に** Agent ツールで起動し、スナップショットの内容を渡す。
- `ta-analyst` → `01_analyst.md`
- `ta-researcher` → `02_researcher.md`

## 2. 強気派・弱気派の討論
- ラウンド1: `ta-bull` と `ta-bear` を並列に起動し、01と02のレポートを渡す。
- ラウンド2以降: 相手の直前の主張を渡して反論させる(並列でよい)。
- 全ラウンドを `03_debate.md` にまとめて保存する(ラウンドごとに見出しを付ける)。

## 3. トレーダー
`ta-trader` に 00〜03 を渡す → `04_trader.md`

## 4. リスク管理(最終承認)
`ta-risk-manager` に 00〜04 を渡す → `05_final.md`

## 5. 報告
ユーザーには `05_final.md` の要点を返す: 最終判断、売買計画表、主要イベント(JST)、免責文。各レポートの保存場所も伝える。

## メモ
- サブエージェントは他のサブエージェントを起動できないので、受け渡しはメインセッションが行う。
- 各エージェントには、前の工程のレポート本文をそのままプロンプトに含めて渡す。
